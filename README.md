# 讓 Grok Bot 的電腦不要睡著

改寫自 [realTaki/bot-keepalive](https://github.com/realTaki/bot-keepalive)（MIT 授權）。

## 遇到什麼問題？

Grok Bot 有一台自己的雲端電腦。
只要大約 5 到 7 分鐘沒在跟它互動，這台電腦就會自己「睡著」，就像手機放著不動會自動鎖螢幕。

平常沒關係，但如果你請它跑一件很久的事（例如整理大量資料、跑一個要一小時的程式），電腦一睡著，事情就做到一半停住了。

## 這個能幫你什麼？

裝上以後，你的 Grok Bot 就會在長工作跑完之前讓電腦保持清醒，跑完再讓它休息。你不用自己盯著，也不用一直傳訊息叫醒它。

## 為什麼不用排程（Routine）定時叫醒？

很多人第一個想到的是：設一個排程，每隔幾分鐘叫 Grok Bot 一次，電腦不就不會睡了嗎？

不建議這樣做，因為**很耗額度**。

Bot 每被叫醒一次，都要把之前的對話、記憶和各種規則從頭讀一遍，才知道自己在做什麼。就像每次叫醒一個人，他都要先把整本筆記重看一次才能開始工作。叫醒的次數一多，光是「重新讀一遍」就會用掉大量 token。

另外，排程最短 5 分鐘才能跑一次，而且常常會晚一點才開始，剛好卡在電腦快睡著的時候，不一定救得到。

這個方法不一樣：它從頭到尾只讓 Bot 安靜地「等著」，不用反覆醒來重讀，所以比排程省很多。

## 怎麼用？（兩步）

**第 1 步：把下面這段話複製，貼給你的 Grok Bot。**

```
請幫我把這個 skill 存起來，以後跑長時間工作都照它做：
https://github.com/pikainjapan0003/bot-keepalive-zh/blob/main/skills/bot-keepalive/SKILL.md
```

**第 2 步：以後要跑很久的工作時，多加一句話。**

```
這個工作會跑很久，請開守護，到 ○○ 點為止。
```

就這樣。

## 使用前要知道的事

- **會多花一點額度**：電腦醒著的時間也算在使用量裡，所以只在真的要跑很久的工作才開。跑超過 2 小時的工作，建議先問 Grok Bot 有沒有更省的方法。
- **記得說要到幾點**：給一個結束時間，時間到它就會停，不會一直花下去。
- **如果中途停了**：再跟 Grok Bot 說一次「請繼續守護」就好，工作本身不會壞掉。
- **不是每件事都需要**：幾分鐘就能做完的事，或是在別的網站上跑的工作，都不用開。
- **這是暫時的方法**：哪天 Grok Bot 官方不再讓電腦自己睡著，就不需要它了。
